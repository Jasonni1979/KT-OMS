## 关键设计决策（速览）

| 决策 | 说明 |
|---|---|
| 三元库存记账 | 仓 × SKU × **货主**（代运营多品牌货权隔离，区别于商派单货主模型） |
| 货主维度贯穿 | 全部业务/财务单据携带 owner_id（补齐商派最大缺口） |
| 租户级行隔离 | 品牌方多租户门户 + SaaS 化预留 |
| 自建平台 Gateway | 替代商派矩阵中心（其开源版硬依赖商派 SaaS 网关，且无抖音适配） |
| 四套订单状态机 | audit / fulfill / pay / ship 分离（收敛商派 process_status 混用） |
| 审单插件链 + 拆单 16 策略 | 可插拔注册表模式，继承商派 20 年机制精华、新栈重写 |

## 里程碑

M0 技术验证（2-4 周：框架 spike + gateway 打通淘宝拉单 + 三元库存 Lua 预占原型）→ M1 正向履约+库存 → M2 售后+6平台+多WMS → M3 采购+财务+门户+价格 → M4 迁移灰度（按品牌切换）。4-6 人 × 7-8 个月。
