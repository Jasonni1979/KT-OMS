## 2. 逐项分析详情

### G1 即时零售（判定：真缺口，取决于业务）
行业现状：美团闪购/饿了么/京东到家/抖音小时达/淘宝小时达已成线下门店品牌标配渠道；美妆品牌（凯淳主力品类）在美团闪购增长显著。技术要点：① 即时零售平台订单接入（gateway 新适配器，报文含配送时效约束）② 门店库存秒级同步（比常规电商同步时效要求高一个量级）③ 骑手运力对接（呼叫/比价/轨迹/交接确认）④ 分钟级履约时效监控。
**若凯淳服务的品牌有门店且入驻即时零售平台 → 需补 D03.15 即时零售履约 + D02 适配器扩展 + D09 运力对接；若没有 → 维持 P2 预留即可。**

### G2 智能风控（判定：强度选择）
基础风控（黑名单/地址规则/大额复审）我们已有。友商强化项的 ROI：地图 API 地址校验（成本低效果直接，建议补）、限购规则（大促防黄牛刚需，规则引擎即可承载，成本低）、AI 行为画像（需数据积累+算法投入，建议 P2 借 K-AIDE）、行业黑名单库（第三方数据源采购问题，非纯技术）。

### G3 活动锁定库存（判定：大促场景刚需候选）
与 D04.08 现有三策略正交：活动锁定是「从共享池中为特定活动/直播间/平台圈占专属库存，带生效窗口与释放规则」。商派同样有此能力（console.store_freeze_log 活动冻结）。若凯淳品牌方常做大促/直播专场（美妆行业常态），此能力缺失会导致活动超卖或库存利用率低。**建议补入 D04.08 作为第四种策略或独立「活动库存」子模块（P1）。**

### G4 DOM 算法路由（判定：分阶段）
规则式分仓（我们现状）覆盖 80% 场景；算法优化的价值在多仓网络成熟后（运费节省 5-15%）。凯淳当前多仓+多 WMS 刚起步，**建议 M1 规则式 + 路由决策日志埋点（为算法积累数据），仿真沙盘 P2，算法优化视单量与仓网复杂度再启动**。规则编排的可视化配置（万里牛拖拽式）值得在 D03.06 增强。

### G5 礼品卡/储值（判定：范围确认）
若私域（微信小店/小程序）订单存在储值卡/礼品卡支付 → 影响 D03.01 支付方式模型与 D08 应收口径（卡兑付是预收负债）。**若没有此类业务，显式声明边界即可。**

### G6 PIM（判定：建议边界外）
商品刊登/素材/详情页生成是独立产品域（百秋 PIM 单独售卖），与 OMS 的物料档案（履约视角）职责不同。行业惯例 OMS 不做 PIM。**建议在 README §8 边界声明补充，若凯淳有刊登需求另立项目。**

### G7 AI 销量预测（判定：P2 增强）
D04.10 统计式补货建议先跑，积累数据后经 K-AIDE Agent 通道引入预测模型（Q41 已预留接口）。不建议首期投入。
