# 平台接口与资质依赖清单（集中标注）

> 文档编号：DEP-01 · 版本 V1.0 · 2026-10-24 · 编写：小凯 · 状态：待审阅
> 定位：全库 SRS 中散落的**平台接口权限 / 外部服务资质 / 账号开通**依赖的**单一登记源**（Jason 决策：资质部分做好标注即可——本文档即集中标注，不展开申请流程）
> 用法：①M0 启动时按「里程碑」列排申请计划（审核周期长的先启动）②各模块开发前查本清单确认前置依赖 ③状态列由项目组维护更新
> 登记范围：6 电商平台 + 外部服务商（地图/短信/发票/轨迹/同城/WMS/报关）；不含内部系统（泛微 OA/金蝶/通天晓走商务对接，另列 §4）

## 3. 申请节奏建议（按审核周期与里程碑倒排）

| 批次 | 启动时点 | 项目 | 理由 |
|---|---|---|---|
| **第一批（本周）** | M0 前 | DY1 抖音服务商资质、T1/T2 淘系应用+交易权限、J1 京东应用 | 审核周期最长（抖音服务商资质数周级）；M0 gateway spike 打通淘宝拉单需要 T1/T2 |
| 第二批 | M1 前 | T3 TMC、T6 菜鸟面单、P1/P2 拼多多、S1 地图、S2 短信 | M1 正向履约主链路硬依赖（面单/消息） |
| 第三批 | M2 前 | DY2/DY3/DY6 抖音业务包、X1/X2 小红书、V1-V3 唯品会、T7 奇门、S5 轨迹、I1-I5 即时零售 | M2 全平台适配+多 WMS |
| 第四批 | M3 前 | T5/J3/P3/DY4 改价权限、S4 发票服务商、S6 预测服务定档、T8 节点上报 | M3 价格管理/财务/AI 预测 |
| 业务触发 | 启动时 | S7 鉴定机构、S8/S9 报关与海关接口 | P2 预留位，业务落地再申请 |

**风险提示（已在各 SRS 标注，此处汇总）**：
1. 抖音=最高风险项：资质审核周期长 + 开源商派无适配参考（全从零），DY1 必须最先启动；
2. 改价 API（T5/J3/P3/DY4）普遍有类目/权限包限制，**M3 前完成六平台价格写能力资质盘点**（D04.11 §8 风险①），未获批平台按档案模式降级运行——功能可分期，不阻塞上线；
3. 所有降级路径已在对应 SRS 设计（消息推送→轮询、地图 API→规则校验、改价回传→档案模式、轨迹→占位），资质延迟不会导致主链路停摆，仅体验/自动化程度降级。
