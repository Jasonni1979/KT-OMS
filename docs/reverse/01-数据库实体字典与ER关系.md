## 2. 核心域实体详解

> 订单域是系统心脏。以下按域展开核心表的全部列定义。其余 500+ 张表在 §3 提供全量索引（表名+注释），需要时再逐表展开。


### 2.0 全局实体关系总览

```mermaid
erDiagram
    shop ||--o{ orders : "店铺接单"
    members ||--o{ orders : "会员下单"
    orders ||--|{ order_items : "订单行"
    orders ||--o{ order_objects : "订单对象(包裹单元)"
    order_items ||--o{ products : "对应商品SKU"
    goods ||--|{ products : "SPU-SKU"
    orders ||--o{ payments : "支付单"
    orders ||--o{ delivery : "发货单"
    delivery ||--|{ delivery_items : "发货明细"
    delivery }o--|| dly_corp : "物流公司"
    orders ||--o{ refunds : "退款单"
    orders ||--o{ return_product : "退货单"
    return_product ||--o{ return_product_items : "退货明细"
    return_product ||--o{ return_reshipping : "换货补发"
    branch ||--o{ branch_product : "仓库库存"
    products ||--o{ branch_product : "SKU库存分布"
    branch_product ||--o{ iostock : "出入库流水"
    orders ||--o{ order_receiver : "收货人"
    orders ||--o{ order_pmt : "优惠分摊"
```

订单主链：`shop/members → orders → order_items/products → payments → delivery → (refunds/return_product)`；
库存主链：`branch(仓) × products(SKU) → branch_product(库存) → iostock(流水)`。
