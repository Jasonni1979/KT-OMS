## 5. 风险与依赖提醒

1. **抖音开放平台资质**：申请有审核周期，本周启动。
2. **近 3 年订单迁移**：330万-2200万单量级，迁移工具与清洗规则需在 M1 并行启动设计，不能等开发完再做。
3. **多 WMS 路由**：需尽早拿到通天晓接口文档与第二家 WMS 的接口形态，适配层抽象以此为准。
4. **金蝶接口**：需财务部门确认金蝶版本（K3/EAS/云星空）与开放接口形态，决定集成层设计。
5. **按品牌灰度切换**：要求新旧系统并行期库存不双扣——切换单元（品牌）内的店铺要么全旧要么全新，库存期初对齐脚本是切换前置条件。
